# Contributing to Ship Carbon Monitor

Thank you for your interest in contributing to the **Marine Vessel Real-Time Carbon Emission Monitoring System**! 🚢🌱

This project aims to provide an accessible, open-source hardware and software stack to monitor, measure, and predict maritime emissions using IoT sensors and AI. We welcome contributions from software developers, hardware engineers, data scientists, and marine researchers.

---

## 📜 Code of Conduct

By participating in this project, you agree to maintain a respectful, inclusive, and collaborative environment for everyone. Please be helpful, open to constructive feedback, and polite in all discussions.

---

## 🚀 How Can You Contribute?

### 1. Reporting Bugs & Issues
If you find a bug, inaccurate calculations, or hardware/sensor integration issues:
1. Check the [Issues](../../issues) tab to see if the problem has already been reported.
2. If not, open a new **Issue**.
3. Clearly describe:
   - What went wrong.
   - Steps to reproduce the issue.
   - Your environment (e.g., Python version, OS, microcontroller/sensor model used).

---

### 2. Suggesting Features & Improvements
Have an idea to improve emission predictive models, add support for new sensors, or optimize code?
1. Open an **Issue** with the tag `enhancement` or `feature request`.
2. Explain the use case and how it benefits the maritime/environmental research community.

---

### 3. Submitting Pull Requests (PRs)
To contribute code, documentation, or hardware schematics directly:

1. **Fork** the repository to your own GitHub account.
